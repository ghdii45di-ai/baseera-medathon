# Current prototype status — simulation finalization

Baseera's public default is a clearly labelled interactive hackathon simulation. The existing bilingual React/TypeScript/Vite layout and device animation were reused. Visitors select a predefined fictional scenario after simulated capture; the report explicitly separates the capture animation, unperformed basic checks, absent validated retinal-quality assessment, disabled inference, and visitor-selected demonstration outcome. The unavailable scenario provides no result or reassurance. There is no hidden fallback from inference to simulation.

The public experience has no uploads or API requests and runs as a static frontend. Simulation state has its own browser key and does not read/write existing research cases. Public API requests are blocked in Vite development/preview, and production static routing rules refuse API calls and support browser routes. The backend defaults to simulation, does not load a model, and rejects image-check/inference endpoints even when the research provider is configured.

The local research workflow, weights, isolated environment, real/synthetic execution records and source/label information are preserved. Explicit frontend/backend research flags are required. Existing image checks remain basic descriptive measurements, not retinal gradability. Five real photographs all produced class 0, including both HRF DR-group photographs. No accuracy or clinical validation is claimed. See [evaluation](evaluation.md) and [recorded results](retinal-results.json). No alternative model was sought or integrated.

The wearable, optics, illumination, capture and device transfer remain conceptual/simulated. No manufactured glasses, health service, device connection, validated retinal detector, medical advice or public inference is supplied. Diraya and the additional interactive glasses prototype are untouched.

The simulation is live at https://baseera-five.vercel.app/. The final implementation was merged into `main` as `bfb9ff3243465ea4b12906772d70659b216b2c3e`; submission cleanup preserves that implementation. See [public deployment](public-deployment.md), [submission audit](submission-audit-2026-11-14.md), [simulation verification](verification-simulation.md), and the historical [research verification](verification-2026-11-13.md).

Initial development and validation are planned in clinics under specialist supervision, subject to safety reviews and approvals. Home use remains a future goal after validation and applicable regulatory authorization. No clinical validation or medical accuracy is established.
